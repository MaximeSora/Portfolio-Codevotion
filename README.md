# Portfolio Codevotion

## AI context database

A structured project context database is available at `src/data/projectContext.json`.

It centralizes conversation-derived information for the main portfolio case studies, including:
- positioning and core story
- real scope and responsibilities
- key decisions
- constraints and hard parts
- credible impact
- product risks (`value`, `usability`, `viability`, `feasibility`)
- process elements to minimize
- visual ideas

Any AI agent or assistant working on this repository should check this file before rewriting, enriching, or reframing the portfolio case studies.
